The first public release of **Chill Mode**: every battery-saving setting on your Windows laptop in one panel. Apply all of them with one click, and undo them all just as easily.

## Download

**[ChillMode-Setup-1.1.0.exe](https://github.com/corum86/chill-mode/releases/download/v1.1.0/ChillMode-Setup-1.1.0.exe)**: run it and accept the admin prompt.

> The installer isn't code-signed yet, so Windows SmartScreen may warn you. Click **More info -> Run anyway**.

Requires Windows 10 or 11. Nothing else needs installing: the app runs on the Windows PowerShell built into Windows.

## Highlights

- **Optimize for battery in one click.** Applies every saving setting at once. **Balanced saver** gives milder savings that keep the laptop responsive.
- **Plugged-in performance is left alone.** Power-plan changes apply only when you're on battery.
- **Full undo.** Your original value for each setting is saved before Chill Mode first changes it, and **Restore original** puts it back.
- **One panel.** Toggles, drop-downs, radio buttons and sliders, each with a short explanation and a *"Will change: X -> Y"* preview before you apply.
- **Hardware-aware.** Settings your laptop doesn't support are greyed out instead of failing.

## What it controls

| Section | Settings |
|---|---|
| **Power & Processor** | Power mode on battery, turbo boost, max CPU state, processor energy preference, passive cooling, Energy saver threshold and brightness |
| **Graphics: Leverage the iGPU** | Pin browsers and everyday apps to the integrated GPU (detected automatically, or add any app), Intel graphics power plan, AMD switchable graphics |
| **Display & Panel** | Refresh-rate cap, brightness on battery, adaptive brightness, dimming, video playback optimization, dark mode, transparency, animations |
| **Browser Efficiency** | Hardware acceleration and background running for Chrome, Edge, Brave and Firefox; Edge efficiency mode, sleeping tabs and startup boost; Chrome/Brave Energy Saver and Memory Saver |
| **Sleep & Timeouts** | Screen off, sleep, hibernate, lid-close action |
| **Wireless & Devices** | Wi-Fi power saving, PCIe link power management, USB selective suspend, disk idle, Bluetooth on/off |
| **Background & System** | Store apps in the background, search indexing on battery, background game recording |

## Installer

- Installs to `C:\Program Files\Chill Mode` with a green battery icon.
- Start menu entries: **Chill Mode**, **Optimize for battery** (applies the preset without opening the window), **Restore original** and **Uninstall**. Desktop shortcuts are optional.
- Listed in **Settings -> Apps**. When you uninstall, it asks whether to restore your original settings first.

Prefer not to install? Download the source, double-click `ChillMode.cmd`, and accept the admin prompt.

## Good to know

- **Browser settings** are applied as browser policies, so browsers will show *"Managed by your organization"*. Restart the browser for changes to take effect. Choosing **Browser default**, or using Restore, removes them.
- **Refresh rate** is a single Windows display setting with no separate battery value, so it stays capped when you plug in.
- Power-plan changes apply to your **active** plan. If you switch plans, run Chill Mode again.
- The presets never touch **Bluetooth**.
